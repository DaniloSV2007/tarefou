🧩 Tarefou!

Tarefou! é um aplicativo mobile focado em ajudar pais a desenvolverem responsabilidade em seus filhos por meio de tarefas com prazos e recompensas.

O app permite criar listas de tarefas personalizadas, definir prêmios ao completar tudo dentro do prazo e acompanhar o progresso. Voltado principalmente para crianças e adolescentes, o Tarefou! combina organização com gamificação de forma leve e educativa.

🚀 Funcionalidades principais:

Cadastro e gerenciamento de tarefas

Definição de prazos e recompensas

Interface voltada para usabilidade por pais e filhos

Progresso das tarefas em tempo real

Sistema de "missão cumprida" com incentivo positivo

🛠️ Tecnologias usadas:

React Native com Expo

Expo Router

React Native Paper (UI)

Backend em Node.js com Express e Prisma (ajustar conforme seu stack)
