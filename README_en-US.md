Tarefou! is a mobile application designed to help parents foster responsibility in their children through tasks with deadlines and rewards.

Create personalized task lists, define prizes, and track progress in a fun and light way. Perfect for kids and teens, Tarefou! combines organization with gamification in an educational approach.

---

## ✨ Main Features

- ✅ Task creation and management
- ✅ Set deadlines and rewards
- ✅ Interface designed for both parents and children
- ✅ Real-time progress tracking
- ✅ "Mission accomplished" system with positive reinforcement

---
